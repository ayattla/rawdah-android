# روضة

تطبيق أندرويد ثقافي وتعليمي وألعاب ومسابقات دينية للأطفال من 4 إلى 12 سنة.

## الضوابط
- لا صور لذوات الأرواح: الرسوم نباتات وجمادات وأجرام ومعالم فقط.
- لا موسيقى ولا معازف، ولا إعلانات، ولا صناديق حظ.
- الآيات من نص مصحف المدينة برواية حفص، ولا تُقرأ بالصوت الآلي.
- الأحاديث صحيحة مع التخريج، وكل المحتوى بانتظار اعتماد اللجنة الشرعية.
- لا اتصال بالإنترنت: البيانات على جهاز الأسرة فقط.

## الأقسام
بيت القصص، المدرسة (قرآن، دروس، أذكار)، ساحة الألعاب (صيد الحروف بمحرك Flame، ترتيب الوضوء، المطابقة)،
المسابقات (تحدي اليوم، مسابقة سريعة، مراجعة الأخطاء)، مجلس العائلة، حديقتي (نخلة تنمو، فانوس، عادات الخير، أوسمة)،
ولوحة الوالدين خلف بوابة حماية.

## التقنية
Flutter + Flame، والبناء آلي عبر GitHub Actions، ومعرّف التطبيق `com.rawdah.kids`.
